# my-todo-y

### 締め切り日時が近い順に並べる
1. タスクの優先順位がわからないので、締切日時が近い順になるようにした。
2. まだまだプログラミング言語を知らないので調べて、`my_task`と`shared_task`の後ろに`.order_by(Task.deadline)`を付ければ私のタスクと共有タスクの締切日時が近い順になるようになることが分かった。

### まとめて削除機能
1. 今までは一つずつしか削除できなかったけど、まとめて削除できるようにしたい。
2. Flaskがテンプレートを探す場所の指定方法が間違っていたため`/delete.html`から`/`を取った。一括削除用のチェックボックス列を追加したことで、テーブルの列数が1つ増えたため`colspan`を 6 から 7 に変えた。個別操作のボタンが一括削除用のフォーム送信をトリガーしてしまうのを防ぐため、`<button>`を`<span>`に変更した。

### ヘッダーの追従
1. ヘッダーが下にスクロールしても見れるようにする。
2. classの中身に`sticky-top`を追加すれば固定できる。

### ヘッダーのデザイン変更
1. 全体の色の統一。背景変更に伴って文字の色の変更、太くする。
2. htmlのBootstrapの標準クラスには色が固定された色しかなくて自由度が下がるのでCSSを用いて紺色を追加した。また、バグが起きないように`my-navbar`を追加してクラス分けをしてその中に`background-color: navy`を追加した。
`style`の中に`color: white !important`で白にするようにして、さらに **font-weight: 700 !important** で文字を太くするようにした。また、変更にともなってヘッダーの角張の統一で`border-top-left-radius: 0.375rem !important`のtop, bottom, left, rightの4つ追加した。
