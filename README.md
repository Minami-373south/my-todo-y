#9まとめて削除機能

2.Flaskがテンプレートを探す場所の指定方法が間違っていたため/delete.html から / を取た。一括削除用のチェックボックス列を追加したことで、テーブルの列数が1つ増えたためcolspan を 6 から 7 に変えた。個別操作のボタンが一括削除用のフォーム送信をトリガーしてしまうのを防ぐため、<button> を <span> に変更した

#18ヘッダーのデザイン変更　　
1.全体の色の統一。背景変更に伴って文字の色の変更、太くする。　　
2.htmlのBootstrapの標準クラスには色が固定された色しかなくて自由度が下がるのでcssを用いて紺色を追加した。また、バグが起きないようにmy-navbarを追加してクラス分けをしてその中にbackground-color: navyを追加した。styleの中にcolor: white !importantで白にするようにしてさらに**font-weight: 700 !important;**で文字を太くするようにした。また、へんこうにともなってヘッダーの角張の統一でborder-top-left-radius: 0.375rem !important;のtop.bottom.left.rightの４つ追加した。
